Questions fréquentes

Qu'est-ce que le code de parrainage Tesla m'apporte en tant qu'acheteur ?

Tesla fixe la récompense par pays et la modifie régulièrement. Selon la campagne en cours, il peut s'agir d'une réduction sur le prix d'achat, de kilomètres de Supercharge offerts, ou de crédits à dépenser dans l'application Tesla. Consultez la page de parrainage officielle de Tesla pour le montant applicable en Belgique le jour de votre commande — ce site ne peut promettre aucun montant précis.

Comment appliquer le code de parrainage à ma commande Tesla ?

Ouvrez le lien de parrainage avant de configurer votre voiture, ou collez le code dans le champ de parrainage de la page de commande. Le code doit être en place avant que vous confirmiez et payiez les frais de commande. Vérifiez ensuite que le parrainage apparaît dans le récapitulatif ou dans l'application Tesla.

Puis-je ajouter un code de parrainage après avoir commandé ?

Non. Tesla ne compte qu'un parrainage rattaché au moment de la commande. Une fois la commande confirmée, le champ de parrainage est verrouillé et le service client ne peut plus ajouter de code. Si vous n'avez pas encore commandé, utilisez d'abord le lien.

Utiliser un code de parrainage me coûte-t-il quelque chose ?

Non. Vous payez exactement le même prix pour la voiture. Le programme de parrainage est le dispositif marketing de Tesla : l'acheteur reçoit le bonus en cours et le parrain reçoit des crédits de Tesla. Il n'y a ni frais supplémentaires ni intermédiaire.

Le code de parrainage fonctionne-t-il en dehors de la Belgique ?

Le code lui-même n'est pas lié à un pays, mais la récompense l'est : Tesla gère le programme marché par marché, donc ce que vous recevez aux Pays-Bas, en France ou en Allemagne peut différer de la Belgique, et dans certains marchés le programme est suspendu. Vérifiez la page de parrainage de Tesla pour votre pays de livraison avant de commander.
